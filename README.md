# Android Development

Coursework for the Android Development course at KBTU. One folder per assignment.

| Assignment | Contents |
| --- | --- |
| [SIS1](SIS1/) | Nazar, an Android app that works out where your attention actually goes from the phone's own usage events |
| [SIS2](SIS2/) | Five Easy LeetCode problems solved in Kotlin |

## SIS1

Kotlin and Jetpack Compose. Idea, flow chart and build instructions are in
[SIS1/README.md](SIS1/README.md).

```bash
cd SIS1 && ./gradlew test assembleDebug
```
